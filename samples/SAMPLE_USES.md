
How to Use These Samples in the UI (http://localhost:5173)

1. Start the app with ./run_lan.sh and click [New RFP].
2. Test Sample-Driven Mode:
	• Client Bank Name: Banco Horizonte
	• Language: English (en)
	• Primary RFP File: Select samples/Sample_BFS_Core_Banking_RFP.docx
	• Sample PPT: Select samples/Sample_Deal_Brief_Template.pptx
	• Sample Excel: Select samples/Sample_Questionnaire_Template.xlsx
	• Click [Launch Phase 1 Triage] and download the generated .pptx and .xlsx files to see your static headings, subheadings, columns, and baseline classification preserved and populated.
