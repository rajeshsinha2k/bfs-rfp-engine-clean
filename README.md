# bfs-rfp-engine

Local-first Banking & Financial Services (BFS) Pre-Sales RFP processing engine built with Python (FastAPI, LangGraph, SQLite) and TypeScript (React, Vite).

## Local Setup

1. Create a Python virtual environment in `backend/.venv` and install `backend/requirements.txt`.
2. Copy `backend/.env.example` to `backend/.env`.
3. Install frontend dependencies inside `frontend/` via `npm install`.
4. Run backend tests with `pytest -v`.
